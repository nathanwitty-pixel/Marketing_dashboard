Things to know

  • Till sales only. Corporate bags are not in this forecast, so these numbers are lower than the Sales card and are not compared with the monthly target.
  • Big one-off events are a blind spot. November's Black Friday jump was missed by both methods. Chronos can be told about known events and offers in advance. That's the next improvement.
  • Runs on the laptop. The model is too heavy for Streamlit Cloud, so it would run with the morning refresh and the dashboard would show the result.

Does teaching it more make it better?

The five ways of projecting the month

  • Straight line: today's method.
  • Chronos as downloaded: only sees past daily sales (the version above).
  • + Calendar: also told in advance about the Black Friday run-up, the Christmas run-up, Kenyan public holidays and payday days.
  • + Trained on Denri: the calendar version, fine-tuned on every shop's daily sales. It was retrained each quarter on sales from before that quarter only, so it never saw the months it was tested on.
  • Shops added up: the trained model forecasts each shop separately and the forecasts are added together.
